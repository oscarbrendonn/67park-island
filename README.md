# 67 Park Island

Play in the browser: https://oscarbrendonn.github.io/67park-island/

This repository hosts the static web build of the 67 Park island on GitHub Pages. The island, the character, skateboarding and the practice modes run entirely in the browser. Online rooms and friends need the game server, so they are not available on this static host.

The game source lives in a separate private repository; this repository only contains the built site.
